打开 `index.html` 即可运行（纯静态，无需构建、无外部依赖）。

## 二、复刻方式：固定画布 + 等比缩放

`#stage` 是一块 **1866 × 2246 px 的固定画布**，用 `transform: scale(min(vw/1866, vh/2246))` 铺满窗口。

这样做的好处：**版面比例与视频完全一致**，不会因为窗口大小改变栅格比例；面板坐标可以直接写视频里量出来的像素值（见 `assets/css/screen.css` 的 `#pnCore … #pnState`）。

## 四、MEDUSA（章鱼/水母）系统 —— 本项目的重点

### 4.1 造型（程序化 Canvas 绘制，无贴图）

从视频里实测：**本体 ≈ 205 × 285 px，高宽比 ≈ 1.4 : 1**，触手末端挂着发光小方块。据此用 Canvas 逐部件绘制：

- **伞盖**：钟形轮廓 + 5 道横向堆叠环（越往下越宽，带下沿阴影）+ 7 条纵向经线 + 顶部平顶帽 + 2 块状高光 + 左青右粉的边缘光
- **中心核心**：伞盖下方的锥形机械核心，4 道横向分层环 + 底部基座椭圆
- **触手**：14 根，每根 5 段直线拼接（机械连杆感），关节处画圆点 + 横向短杠，末端内收微卷
- **数据接口**：每根触手末端一个方形端子（白底 + 深色内芯 + 外发光）
- **姿态**：伞盖整体随速度轻微倾斜，触手随速度向后拖曳（`bend`），并有呼吸式脉动

### 4.2 行为状态机（携带数据块的核心逻辑）

```
SEEK ──到达停靠点──► GRAB / READ ──► CARRY ──到达目标面板──► WRITE ──► SEEK …
```

- **SEEK**：沿二次贝塞尔弧线飞向目标面板的停靠点（中点向侧向偏移，避免贴着面板直飞）
- **GRAB / READ**：停在停靠点，标签实时显示 `READ x.x KB`，同时**从面板数据口射出一条虚线光束**到生物身上；数据块（3–5 枚）在此刻生成并吸附到触手末端
- **CARRY**：携带数据块飞向另一个面板，数据块用弹簧跟随触手末端，飞行时明显拖曳摆动
- **WRITE**：到达后面板边框闪光，数据块脱离并飞向该面板的数据口后消失；同时往 LIFE 日志写入一条 `MEDUSA-0x wrote $TOKEN → 面板名 · xxK`，`OBSERVATIONS IN / DECISIONS OUT` 计数 +1

### 4.3 停靠点与航线

9 个停靠点全部来自视频逐帧追踪（把每帧里生物的位置按面板聚类得到的稳定坐标），见 `assets/js/app.js` 的 `DOCKS`：

| key | 归一化坐标 | 对应面板 |
|---|---|---|
| core | 0.130, 0.135 | CORE MODEL |
| life | 0.400, 0.085 | LIFE OF A DECISION |
| ent | 0.849, 0.129 | ENTANGLEMENT MAP |
| curve | 0.570, 0.215 | WHERE CURVE |
| orbL | 0.072, 0.486 | THE ORB（左缘） |
| orbC | 0.550, 0.365 | THE ORB（中部） |
| stack | 0.822, 0.479 | DECISION STACK |
| agents | 0.360, 0.860 | SIX AGENTS |
| state | 0.720, 0.855 | STATE BUILDER |

4 只 MEDUSA 各有偏好航线，并且有**停靠点互斥预订表**（`OCCUPIED`）——同一时刻一个停靠点只停一只，避免多只挤在同一处、标签互相压叠。

## 六、调试

- `index.html?warp=15` —— 启动时把 MEDUSA 快进 15 秒（用于截取不同时刻的画面）
- 浏览器窗口任意缩放，版面比例保持不变

## 七、已知差距

- 原站用的是真实 3D 模型（金属材质、真实光照），本复刻用 Canvas 2D 程序化绘制，材质细腻度仍有差距
- 面板内的具体数值/币种是随机生成的（原视频本身就是动态数据），文字风格与结构已对齐
- 原视频 24 秒内的部分瞬时特效（如偶发的强闪光）未逐帧还原
